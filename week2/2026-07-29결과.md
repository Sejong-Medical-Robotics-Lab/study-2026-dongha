## 3.4 자율학습 미션 A - 상태 토픽 조사

### 1. Low State에 담긴 관절 데이터
- 관절 데이터 개수: **29개**
- 각 관절에 저장되는 값: **관절 각도(q), 관절 속도(dq), 관절 토크(τ)**
- 관절 데이터 개수는 G1의 **29 DoF**와 일치하였다.

### 2. 상태 보고 주기
휴머노이드는 Go2나 turtlesim보다 더 빠른 상태 갱신이 필요하다.  
두 발로 균형을 유지해야 하므로 작은 자세 변화에도 빠르게 반응해야 하며, 상태 갱신이 느리면 균형을 잃거나 넘어질 수 있다.

### 3. DDS 자동 발견으로 생기는 문제와 해결 방법
같은 네트워크에서 다른 학생의 ROS2 토픽이나 노드가 자동으로 발견되어 서로 간섭할 수 있다.  
이를 방지하기 위해 **ROS_DOMAIN_ID**를 각자 다른 값으로 설정하여 통신 영역을 분리한다.

### 4. 관절 하나 추적하기
왼쪽 발목 관절의 각도(q)를 약 10초 동안 관찰한 결과, 값은 거의 일정하게 유지되었으며 아주 작은 변화만 나타났다.  
이는 자세 보상 제어가 지속적으로 이루어져 로봇이 안정적으로 균형을 유지하고 있음을 보여준다.

## 3.4 자율학습 미션 B - 나만의 데이터 흐름 지도

### Low State
- 토픽 이름: `/g1/lowstate`
- 메시지 타입: `g1_edu_interfaces/msg/LowState`
- 상태 보고 주기: **약 29 Hz**

### 모션/보행 명령
- SDK를 통해 명령을 전송하여 로봇의 동작을 제어한다.

### Mode State
- 토픽 이름: `/g1/mode`
- 메시지 타입: `g1_edu_interfaces/msg/ModeState`
- 상태 보고 주기: **약 5 Hz**
