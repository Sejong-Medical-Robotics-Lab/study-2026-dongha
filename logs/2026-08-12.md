# 학습일지 - 2026-08-12

## 오늘 배운 것 (3줄 요약)
- Go2는 총 12개의 자유도를 가지며, 다리 하나당 고관절 2개와 무릎 1개로 3자유도가 구성된다.
- 4D LiDAR을 이용해 주변 물체까지의 거리와 위치를 측정해서 3차원 공간을 파악하고, 전방 카메라를 이용해
로봇 앞쪽의 영상, 모양, 색 등을 확인하며, IMU를 이용해 로봇의 기울기,각속도,가속도를 측정해서 균형 유지에 사용한다.
- 오도메트리는 다리의 움직임과 IMU를 이용해 로봇의 이동량을 누적하여 현재 위치를 추정하는 방법이다. 

## 직접 해본 것 / 성공한 것
- 토픽을 확인해 속도명령은 /cmd_vel, 로봇 이동 상태는	/odom, 관절 상태는 /joint_states, 
 발 접촉 상태는 /foot_contacts인것을 알았다.
- teleop을 이용해 키보드로 Gazebo 시뮬레이션 안의 Go2를 직접 움직여 보았으며, 로봇이 움직일 때 
 /cmd_vel에서는 속도 명령이 변하고 /odom에서는 로봇의 이동 상태와 위치 정보가 변하는 것을 확인했다.
- /cmd_vel에 직접 속도 명령을 발행하여 Go2를 직진, 제자리 회전, 원 궤적으로 움직여 보았으며, 
다른 터미널에서 /odom을 확인하면서 입력한 속도 명령에 따라 로봇의 이동 상태가 어떻게 변하는지 비교하였다.

## 막힌 것 / 이해가 안 되는 것 (다음 Q&A 때 질문할 목록)
- Go2의 보행 패턴에서 왜 trot이 기본 보행으로 사용되는지 처음에는 단순히 빠르게 걷기 위한 방식이라고 생각했지만,
실제로는 속도뿐만 아니라 로봇의 안정성과도 관련되어 있다는 점이 이해하기 어려웠다. 이후 시뮬레이션에서 Go2를 직접 움직여 
보면서 대각선 방향의 두 다리가 번갈아 움직이는 것을 확인하고, 한쪽 다리를 움직일 때 다른 다리들이 몸을 지지하는 모습을 
관찰하면서 trot이 속도와 안정성을 동시에 고려한 보행 방식이라는 것을 이해할 수 있었다.

## 한 줄 소감
- 처음에는 Go2의 움직임을 단순한 명령의 결과라고 생각했지만, 직접 시뮬레이션을 해보면서 보행 패턴과 센서 데이터가 
로봇의 움직임과 균형에 밀접하게 연결되어 있다는 것을 이해할 수 있었다.
